# Contributing

Short version: small branches, green CI, conventional titles, human review. The full process — local gates, what to run before pushing, ground rules — lives in [`CONTRIBUTING.md`](https://github.com/CHE3MZ/gitagger/blob/master/CONTRIBUTING.md) in the repo. Start there.

<img src="../assets/guide-images/fork-guide.png" alt="Fork guide" width="256" />

The one thing worth repeating: **make sure every workflow is green before opening the PR** (`gh run watch`), and never cut tags or releases — the maintainer handles all of that.
